================================================================
RUNBOOK OPENSHIFT - FINAL PROJECT CI/CD (untuk Q4, Q6, Q7, Q8)
Jalankan di lab Coursera (butuh cluster OpenShift lab).
================================================================

cd ~/ci-cd-final-project          # atau folder repo di lab

# 0) (sekali) beri SA "pipeline" hak admin di project — untuk deploy:
oc create rolebinding pipeline-admin --clusterrole=admin \
  --serviceaccount=$(oc project -q):pipeline -n $(oc project -q) || true

# 1) PVC (Q4: Console -> Storage -> PersistentVolumeClaims -> oc-lab-pvc
#    -> screenshot, simpan sebagai oc-pipelines-console-pvc-details.png).
#    Manifest ada di .tekton/pvc.yaml (name oc-lab-pvc, ReadWriteOnce,
#    storageClassName skills-network-learner, 1Gi):
oc apply -f .tekton/pvc.yaml

# 2) Pasang tasks + pipeline dari repo:
oc apply -f .tekton/tasks.yml
oc apply -f .tekton/pipeline.yaml

# 3) Jalankan pipeline (6 langkah: cleanup -> git-clone -> flake8 ->
#    nose -> buildah -> deploy). Workspace bernama "output":
tkn pipeline start oc-pipelines-oc-final \
  -w name=output,claimName=oc-lab-pvc \
  -p repo-url=https://github.com/fansclubcoding/ci-cd-final-project.git \
  -p build-image=image-registry.openshift-image-registry.svc:5000/$(oc project -q)/cd-final:latest \
  -p app-name=cd-final \
  --showlog
# (alternatif GUI: Console -> Pipelines -> oc-pipelines-oc-final -> Start)

# 4) Tunggu Succeeded (3-6 menit).

# 5) Q6: Console -> Pipelines -> oc-pipelines-oc-final -> screenshot detail.
#    Simpan sebagai oc-pipelines-oc-final.png

# 6) Q7: Console -> Pipelines -> PipelineRuns -> run hijau terbaru ->
#    screenshot, simpan sebagai oc-pipelines-oc-green.png

# 7) Q8: log aplikasi — harus memuat banner "S E R V I C E   R U N N I N G":
oc logs deployment/cd-final
#    atau Console -> Workloads -> Deployments -> cd-final -> Pods -> Logs
#    Simpan teksnya (Q8).

## TROUBLESHOOT
- Deploy task gagal 403: jalankan ulang langkah 0, lalu retry pipelinerun:
  tkn pipelinerun retry $(tkn pipelinerun ls -n 1 -o jsonpath='{.items[0].metadata.name}')
- Buildah gagal push registry: pastikan project aktif benar dan
  TLSVERIFY=false (sudah di pipeline.yaml).
- git-clone / buildah / openshift-client ClusterTask tidak ada:
  pasang dari Tekton Hub di namespace project lebih dulu, contoh:
  tkn hub install task git-clone --namespace $(oc project -q)
- storageClassName skills-network-learner tidak ada di cluster:
  hapus baris storageClassName dari .tekton/pvc.yaml lalu oc apply ulang.
- tkn tidak ada: pakai GUI console untuk start, hasilnya sama.
